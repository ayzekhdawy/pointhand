# Community launch kit

These are copy-ready drafts for the owner's accounts. Creating this file does not post to social networks.

## English

I built PointHand, an open-source Windows computer-use MCP server with a TypeScript client and a native Rust host.

The demo recreates the Mona Lisa in Microsoft Paint through mouse strokes rather than pasting a bitmap. PointHand provides screenshots, UI Automation, mouse/keyboard input and a visible native overlay.

Alpha 2 is available for supervised workflows. I am looking for Windows testers, Rust/TypeScript contributors and people who want to build creative examples. You can contribute without writing code: clean-install reports, app compatibility checks and mixed-DPI tests help us improve.

Watch the demo and try it: https://github.com/ayzekhdawy/pointhand
Start contributing: https://github.com/ayzekhdawy/pointhand/contribute

## Posting and follow-up

Attach `examples/mona-lisa/demo.mp4` or the GIF. Use the actual demo; do not imply untested apps or monitor configurations are supported. Adapt the text to each community's rules. Start with the owner's accounts and relevant Windows, Rust and MCP communities.

Track successful installations, useful reports and first outside contributions. Acknowledge contributors and link fixes in periodic updates. The maintainer should choose a realistic response cadence rather than promise immediate review.

Official MCP Registry publication is a separate follow-up: first confirm a supported distribution and publisher metadata. No registry listing is claimed by this launch.
